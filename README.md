# Instant JSON Formatter CLI
A fast, lightweight command-line tool for formatting, minifying, validating, and colorizing JSON. Built for developers who want quick, reliable JSON utilities without heavy dependencies.

## Features
- Pretty-print JSON with clean indentation
- Minify JSON for compact output
- Validate JSON structure
- Optional colorized output using Pygments
- Zero heavy dependencies
- Works on Windows, macOS, and Linux
- Simple, readable codebase

## Installation

```bash

git clone https://github.com/FreshLua/jsonfmt.git

cd jsonfmt

pip install -r requirements.txt


```


## How To Use 

```bash

python src/cli.py examples/sample.json

python src/cli.py examples/sample.json --minify

python src/cli.py examples/sample.json --validate

python src/cli.py examples/sample.json --color

```
